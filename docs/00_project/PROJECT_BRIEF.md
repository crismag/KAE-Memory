# Project Brief

## Product

KAE-Memory is the persistent-memory foundation for an AI-native software
engineering platform. Multiple specialised AI agents will collaborate across
requirements, research, architecture, implementation, testing, review,
documentation, and project management while sharing durable project knowledge.

## Problem

AI coding assistants are usually session-oriented. Long-running projects suffer
from lost context, repeated explanation, fragmented requirements, architectural
drift, and weak coordination between different AI tools.

## Intended users

- Independent software developers
- AI-assisted developers
- Engineering teams
- Solution architects
- Technical consultants
- Technical founders

## Desired outcome

AI agents should function as long-term engineering collaborators that retrieve
and apply project knowledge consistently across sessions rather than restarting
from isolated conversations.

## Governance

The workflow is human-in-the-loop. Human owners retain product vision,
requirements validation, architecture approval, final technical decisions, and
quality assurance.

## Current phase

Requirements consolidation and source intake. The public implementation
repository is currently treated as greenfield.

## Product boundary

KAE-Memory is the durable shared-memory foundation. The broader AI software
engineering platform may later include orchestration, code execution, review,
testing, user interfaces, integrations, and autonomous workflows, but those
capabilities are not automatically part of the first release.
